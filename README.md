# 🎬 Moodflix

Moodflix is an AI-powered entertainment recommendation platform that suggests movies and music based on a user's mood. The application combines sentiment analysis, facial emotion detection, and machine learning to provide personalized recommendations and an engaging user experience.

## 🚀 Features

- 🎭 Mood Detection from Facial Expressions
- 💬 Text-Based Sentiment Analysis
- 🎵 Personalized Music Recommendations
- 🎬 Personalized Movie Recommendations
- 🤖 AI Chatbot Assistance
- 👤 User Authentication & Profiles
- ⭐ Feedback and Rating System
- 📊 Interactive Dashboard

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/Moodflix.git
cd Moodflix
```

### Backend Setup

```bash
cd backend

python -m venv venv

# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate

pip install -r requirements.txt

uvicorn main:app --reload
```

### Frontend Setup

```bash
cd frontend

npm install

npm start
```

## 🎯 How It Works

1. User enters a mood description or enables webcam access.
2. The system detects emotions using sentiment analysis or facial recognition.
3. AI models analyze the detected mood.
4. Personalized movie and music recommendations are generated.
5. Users can interact with the chatbot and provide feedback.
